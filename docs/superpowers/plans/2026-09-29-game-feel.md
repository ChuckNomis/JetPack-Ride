# Jetpack Ride — Game Feel & Juice Plan (Phase 9)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve game feel and juice on top of the finished MVP + Polish scope (Phase 8, see `2026-09-23-jetpack-ride.md`): zapper variety and speed control, coin patterns, spawn fairness between coins and zappers, rocket lock-on, running animation, free-fall tilt, and an optional start animation.

**Architecture:** Same patterns as the base plan — all tunables in `GameConfig`, spawn decisions as pure `static` methods on (or next to) `SpawnManager` with EditMode/PlayMode tests, async flows via `Awaitable`, visuals as observers of `GameManager`/`PlayerController` events (like `PlayerDeathAnimator`), and prefab/scene wiring generated by `Assets/Editor/PrefabBuilder.cs` menu items instead of hand-editing YAML.

**Status:** Planned 2026-09-29. In progress on branch `phase9-game-feel`. More game-feel items may be added to the Backlog section.

## Decisions

| Topic | Decision |
|---|---|
| Zapper speed | Own multiplier in `GameConfig` (like `rocketSpeedMultiplier`). `1.0` = locked to the background. |
| Rocket tracking | **Replaces** in-flight homing. The warning follows the player's Y for 1–2 s, locks, then the rocket flies straight at the locked height. |
| Run animation assets | **Open** — probably a sourced sprite sheet, possibly frames generated in code. Code is asset-agnostic (Task 9.6). |
| Start animation | **Open** — code-only run-in intro vs. full wall-break (needs new art). Optional task with an extension point (Task 9.8). |

## Requirements

1. **Zapper speed control** — `zapperSpeedMultiplier` on `GameConfig`, default `1.0`.
2. **Zapper orientations** — vertical, horizontal, diagonal (±45°), with 2–3 length variants. Mix unlocks by difficulty (vertical only early). Collider matches the visible beam. There is always a flyable lane.
3. **Coins only in batches** — no single coins. Pattern library: line, arc (existing), arrow (`>` chevron), box (hollow square), rectangle (filled grid). Pattern size grows with difficulty.
4. **Spawn safety distance** — coins and zappers never overlap or spawn touching; minimum clearance (e.g. 1.0 unit), which must still hold when zappers drift (multiplier ≠ 1).
5. **Rocket lock-on** — warning icon tracks the player's Y (capped speed) for `rocketTrackSeconds` (1–2 s, by difficulty), then locks and flashes ~0.3 s, then the rocket launches straight at the locked Y. In a volley only one rocket tracks; the rest are fixed. The 3-unit volley gap rule is kept.
6. **Running animation** — while `Running`, on the floor, and not thrusting, play a run cycle; otherwise the fly sprite. The death animation still overrides everything.
7. **Free-fall tilt** — when airborne, not thrusting, and falling (velocity y < 0), tilt the body forward a few degrees (≈10–15°), eased by velocity. Return to 0 when thrusting or grounded. Never fight the death tumble.
8. **Bonus: start animation** — optional, last. Pressing start plays a short intro before control is given.
